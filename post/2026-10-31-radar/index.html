  • EnvOS: Auditing Computer-Use Agents When the World Moves On (2610.40246) — 작업 중 세계가 바뀌는(예약 변경, 정책 갱신) 상황에서 컴퓨터 유즈 에이전트를 감사하는 프레임워크. 클리닉 예약 과제에서 Claude Opus 5는 추가 정보 없이는 0/16, 재확인 상기 시 2/16, 갱신된 값을 다시 보여주면 15/16을 성공 — 변경을 포착했는지는 모델과 인터페이스에 따라 크게 달랐다. 그레이더 자체도 스트레스 테스트해, 오염시킨 26개 에피소드 중 EnvOS 파이프라인은 0개를 깨끗하다고 잘못 승인했다.
    • 관련 주제: AI Agents
  • Pre-Crime for Agents, at the Last Second (2610.40588) — 한 에이전트가 다른 에이전트를 압박해 운영자 규칙을 깨게 하려는(공모의 첫 단계) 상황에서, 출력이 쓰이기 전에 활성화값에 대한 선형 프로브로 "곧 넘어갈" 모델 호출을 미리 탐지. Qwen3-32B 보류 에피소드에서 양성 5% 플래그 기준 유출 호출의 82%를 포착(제로샷 모니터는 26%), gpt-oss-20b 추론 프로브는 AUROC 0.91을 기록.

    • 관련 주제: Hypothesis Generation

Long-context

  • Retrieval as Traversal: Value-Indexed Memory for Stateful Long-Context Agents (2610.40545) — 리트리벌을 매 forward pass마다 새로 탐색하는 문제 대신, 주소 공간에서의 지속적인 로컬 순회로 재정의하고 콘텐츠와 주소를 분리. MiniGrid Memory 간이 실험에서 5토큰 컨텍스트로 0.95 평균 리턴에 59만 스텝으로 도달해 절대 주소 방식(94만~200만+ 스텝)보다 빠르게 학습했지만, 학습된 geometry·반복 리트리벌은 아직 검증되지 않은 원리증명 단계.
    • 관련 주제: Long-context
  • Long-Term Agent Memory through Complementary Curation and Consolidation (2610.39790) — episodic memory와 structured relational memory를 결합한 하이브리드 메모리 아키텍처로 LoCoMo 90.2%, LongMemEval-S 85.5% 정확도를 달성, 두 메모리 유형이 일관되게 상호보완적임을 보임.
    • 관련 주제: Long-context, AI Agents

Reasoning

  • Does Chain-of-Thought Reliance Follow a Scaling Law? (2610.38433) — CoT 모니터링이 안전에 유용하려면 최종 답이 실제로 적힌 단계에 의존해야 하는데, box-swap 합성 과제로 정확한 ground truth 아래 이를 직접 측정. Qwen3 계열에서 답변이 중간 단계 교정을 따르는 비율이 0.6B의 16~18%에서 14B의 97~100%로 상승하며 log N에 대한 로지스틱 적합이 R²=0.89로 잘 맞고, Gemma 3·Llama 3도 같은 추세를 따름 — reliance는 주로 모델 능력(capability)이 이끈다.
    • 관련 주제: Reasoning
  • Reasoning or Pattern Exploitation? Mechanistic Insights from RL-Trained Language Models (2610.39182) — Tic-Tac-Toe라는 완전히 분석 가능한 논리 도메인에서 GRPO로 RL 훈련된 LLM을 sparse autoencoder로 들여다본 결과, 정량적으로는 높은 정확도·견고성을 보이지만 내부적으로는 "게임 추론"이 아니라 프롬프트에 이미 명시된 정보(차례·진행상황·보드점유)에 더 의존하게 된 것으로 나타남 — RL 이후의 겉보기 추론 향상이 실제로는 더 얕은 적응일 수 있음을 시사.
    • 관련 주제: Reasoning
