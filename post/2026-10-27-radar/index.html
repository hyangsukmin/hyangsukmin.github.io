AI Agents

  • When Agents Fail: Model or Harness--Who's to Blame? (2610.32483) — LLM 에이전트 성능이 모델과 실행 하니스의 결합 산물이라는 점에서, 하니스를 모델과의 상호작용으로 평가하는 프레임워크(Valid Completion Rate·Model-Harness Fit 등 5개 지표)를 제안. 4개 범용 하니스(OpenCode, Codex CLI, Pi CLI, DeepAgents) × 4개 모델을 6개 벤치마크·52,168개 트레이스로 교차 평가해, 하니스 순위가 모델·벤치마크마다 뒤집히며 과제 점수와 완료율이 서로 다른 조합에서 최고를 기록함을 보임.
    • 관련 주제: AI Agents
  • Who Verifies the Tools? How Warped Formatters Mislead Agents and Their Verifiers (2610.32110) — 실제 프로덕션 RAG 연구 시스템에서 도구 계산은 정확했지만 출력 포맷터가 검색 한도·결과 개수 같은 핵심 정보를 누락해 에이전트가 틀린 답을 내고 verifier도 그대로 통과시킨 사례를 분석. 누락 정보를 채운 포맷터로 교체하자 한 실패 유형에서 verifier 오답 수용이 90/90 → 기각 90/90으로 완전히 역전됐고, 같은 감사 프롬프트로 오픈소스 에이전트(OpenClaw, Hermes)의 실제 결함을 찾아 PR까지 머지시킴.
    • 관련 주제: AI Agents
  • Tool-Calling LLM Agents Under Realistic MCP Faults: Scale Does Not Purchase Fault Tolerance (2610.32555) — MCP 생태계의 실제 이슈 57,240건에서 추출한 현실적 장애 분포를 그대로 주입하는 fault-injection 미들웨어로 2개 모델 크기 × 3개 에이전트 스택을 1,350개 조건에서 평가. 영구 장애가 섞인 조건에서 과제 완료 점수가 60% 급락했고, 120B 모델이 20B보다 장애에 더 잘 버티지 못해(p=.96) "모델 스케일이 장애 내성을 사주지 않는다"는 결과를 보임 — 프레임워크 수준 오류 처리가 더 중요하다는 시사점.
    • 관련 주제: AI Agents

AI Scientist / Automated Research

  • POSEIDON: Scaling Training Environments for Scientific Agents from Code Repositories (2610.32448) — 과학 발견 에이전트를 학습시킬 실행·검증 가능한 훈련 환경이 부족한 문제를 겨냥해, 과학 코드 저장소에서 자동으로 환경을 생성하는 파이프라인을 제안. 과학 워크플로를 Reproduction/Subflow/Completion/Correction 4가지 과제 유형으로 분해해 저장소당 기존 접근 대비 약 10배 많은 환경을 뽑아내고, 10개 과학 분야 7,110개 저장소에서 97,659개 환경(Pearl)을 구축 — Qwen3.5 계열이 Pearl로 학습하면 6개 과학-에이전트 벤치마크에서 일관된 향상을 보임.
    • 관련 주제: AI Scientist / Automated Research
  • Can Test-Time Memory Evolution Outperform Test-Time Training for Scientific Discovery? (2610.32046) — 과학 발견에서 test-time training(TTT)이 온라인 가중치 업데이트 비용이 크다는 문제에서, 가중치는 그대로 두고 외부 메모리만 계속 갱신하는 Test-Time Memory Evolution(TTME)을 제안. 동일 발견 프레임워크에서 TTT와 비교했을 때 5개 수학 과제 전부에서 TTME가 TTT를 능가하면서 FLOPs 82.8–84.6%, 실행시간 47.7–58.4%를 절감.
    • 관련 주제: AI Scientist / Automated Research

Hypothesis Generation

  • Principia: Test-Time Hypotheses to Principle Construction for Scientific Discovery (2610.32195) — 과학 발견에서 현상 뒤의 원리를 끌어내는 "가설→원리" 단계가 전문가의 시간·노력을 많이 요구하는 병목이라는 문제의식에서, LLM이 test-time에 비교 인과 가설을 세우고 가설들을 가로질러 반복되는 관계를 귀납 원리로 종합한 뒤 새 관측으로 가설·원리를 계속 재구성하는 순환 프레임워크를 제안. 분자 최적화·단백질 엔지니어링·유전자 섭동·분자 물성 예측 벤치마크에서 내부 지식/외부 검색/경험 요약 베이스라인을 능가하면서 생성된 원리가 실제 과학 문헌과도 합치함을 보임.
    • 관련 주제: Hypothesis Generation, AI Scientist / Automated Research

Long-context

  • Head Dimension Matters in Language Models for Long-Context Retrieval (2610.32213) — 장문맥 검색에서 attention head의 폭(차원)이 성능에 미치는 영향을 체계적으로 분석, 동일 파라미터 예산에서 head를 더 넓게(수는 줄이고) 가져갈수록 장문맥 검색 성능이 오르는 반면 사전학습 손실·짧은 문맥 성능은 거의 영향받지 않음을 발견. attention projection 가중치를 고정해도 넓은 head가 장문맥 지속학습에서 더 나은 적응을 끌어내, 넓은 head가 "검색 head" 비율 자체를 늘린다는 메커니즘을 제시.
    • 관련 주제: Long-context
  • HyScale: Scaling Long-Context Training for Learned Sparse Attention (2610.32057) — DeepSeek-V3.2 이후 production에서 널리 쓰이는 learned sparse attention의 학습 병목이 매 쿼리마다 전체 토큰을 스코어링하는 selection 단계에 있음을 지목, 점수 테이블 없이 즉석에서 정확한 top-k를 구하는 HyTopK와 forward pass의 selection을 재계산에서 재사용하는 selection replay를 제안. GLM-5.1의 100만 토큰 학습을 Megatron-LM 대비 2.07배, DeepSeek-V4-Flash/Qwen3.8-Flash-Next의 해당 레이어도 각각 2.01배/1.57배 가속.
    • 관련 주제: Long-context

Reasoning

  • Free Lunch for LLMs Confidence: The RL Critic Already Knows (2610.31820) — confidence 추정을 위한 별도 학습 비용 문제에서, (질문,응답,정답여부) 트리플만으로 학습한 외부 모델이 정책 모델 내부 표현 없이도 그 정책의 confidence를 똑같이 잘 추정함을 보이고, "정답 여부 기반 outcome 하에서는 confidence 추정과 critic 학습이 동치"임을 증명. value-based RL로 학습된 LLM이라면 기존 critic을 추가 학습 없이 confidence 추정기로 재사용할 수 있고, 12개 도메인에서 모든 in-distribution split 최고 성능·16개 중 14개 최고 calibration을 달성.
    • 관련 주제: Reasoning
  • REACT: Representational Early Analysis and Control of Chain-of-Thought Trajectories (2610.32113) — chain-of-thought(CoT) 생성 중 위험을 조기에 읽어내는 지점과 실제 개입에 가장 효과적인 지점이 같은지를 묻고, 안전/위험 trajectory에서 학습한 방향 벡터를 CoT 초반 hidden state에 한 번 주입하는 개입을 제안. 효과는 2~3번째 토큰의 좁은 창에 집중되고 4~5번째 토큰에서는 거의 0으로 떨어져, 위험 판별 가능성과 개입 효과성이 분리됨을 입증 — DeepSeek-R1-Distill-Llama-8B에서 완전 안전 출력률을 29.06%→82.05%로 끌어올리면서도 무해한 요청 거부율·유용성은 유지.
    • 관련 주제: Reasoning
  • On-Policy Self-Training: Data-Free Self-Improvement in Large Language Models (2610.32770) — 사람이 만든 문제·정답 없이 거친 주제 설명만으로 모델이 스스로 질문과 "특권적(privileged)" 추론 과정을 합성해 자기 커리큘럼을 만들고 self-distillation하는 data-free 자기개선 프레임워크를 제안. 텍스트·멀티모달(VQA) 도메인 모두에서 자기학습하지 않은 도메인의 능력을 유지하면서 표준 언어 벤치마크·VQA에서 일관된 자기개선을 달성.
    • 관련 주제: Reasoning
