  • Predicting Unseen Scientific Interactions: Conditional Flow Models Hallucinate Non-Additive Effects (2610.20288) — 생성모델이 개입 간 상호작용(한 개입이 다른 개입의 효과를 바꾸는가)을 학습·일반화하는지를 생리 시계열·약물 용량반응·복합 세포교란·분자 콘포머 생성에서 검증한다. 개별 효과는 상호작용보다 훨씬 먼저 학습되고, 상호작용이 없는 곳에서도 모델이 상호작용을 "환각"하며, 집계 충실도 지표만으로는 모델이 상호작용을 실제로 학습했는지 가려진다는 것을 보임 — 가설 생성·검증 파이프라인이 생성모델의 외삽 예측을 신뢰할 때 주의할 지점을 제시.

Long-context

  • Cortex: Consolidating Context into Parametric Memory (2610.20399) — 컨텍스트가 준 성능 향상이 컨텍스트 제거 후 사라지는 문제를, 컨텍스트 사용을 예상한 prospective query를 생성해 컨텍스트-조건 출력을 병합 가능한 저랭크/구조적 FFN 업데이트로 증류하는 방법(Memory Consolidation)으로 해결한다. 4B~120B 백본에서 대부분의 설정에서 consolidation-retention 파레토 프런티어 위에 위치하며, 14B 모델에서 50회 순차 사실 편집 후 컨텍스트 유발 이득의 88.9%를 회수하면서 비표적 성능의 99.8%를 유지.
  • MemDuet: Learning Dual-Process Memory for Long-Context Reasoning (2610.19928) — 긴 문서 추론의 성능-효율 트레이드오프를, 작은 모델이 빠르게 증거를 선별(System 1)하고 큰 모델이 느리게 메모리를 검증·갱신(System 2)하는 이중 프로세스로 해결한다. RULER-HQA·LongBench v2·2WikiMultiHopQA에서 RL-MemAgent 대비 종단간 추론 9.74배 가속, 출력 토큰 73.91% 감소.
  • FOLD: Position-Free Far Memory with Local Order for Long-Context Speculative Decoding (2610.20392) — 짧은 시퀀스로 학습된 드래프터가 긴 입력에서 성능이 떨어지는 문제를, 로컬 위치는 정확히 보존하고 먼 항목들은 공유 위치의 "far memory"로 취급해 거리에 따라 주의를 재조정하는 training-free 방법으로 해결한다. 256K 토큰까지 6개 target-drafter 쌍에서 대부분 최고 속도 향상을 보였고 최고 사례는 자기회귀 디코딩 대비 2.08배에서 4.22배로 향상.

Reasoning
